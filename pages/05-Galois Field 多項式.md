## $GF(2^n)$ 與多項式基底

在 $GF(2^n)$ 中，元素以 $x$ 的**多項式基底 (Polynomial Basis)** 表示：

$$A(x) = a_{n-1}x^{n-1} + a_{n-2}x^{n-2} + \dots + a_1x + a_0$$

- **最高次方 $< n$**：剛好對應電腦中的 **$n$ 個 Bits**（第 $0$ 到第 $n-1$ 位元）
- **係數 $a_i \in \{0, 1\}$**：建立在 $GF(2)$ 上，直接對應二進位位元

**對應範例（$GF(2^8)$）：**

$$x^6 + x^4 + x + 1 \;\longleftrightarrow\; \texttt{01010011}$$

---

## $GF(2^n)$ 運算規則

### 1. 加法與減法
- 係數 $\bmod 2$ $\;\Longrightarrow\;$ 等同於二進位 **XOR ($\oplus$)**
- 無進位，且**每個元素的加法反元素就是自己**

### 2. 乘法三步驟
1. **多項式展開**：依一般分配律乘開
2. **係數 $\bmod 2$**：偶數歸 `0`、奇數留 `1`（解決**係數 $> 1$**）
3. **對 $n$ 次不可約多項式 $m(x)$ 取餘數**：將次方壓回 $< n$（解決**次方溢位**）

---

## 尋找不可約多項式 $m(x)$：以 $GF(2^3)$ 為例

- **不可約多項式**：無法被因式分解（如同**質數**）；$3$ 次多項式共有 $2^3 = 8$ 個候選

**篩選規則（淘汰可分解者）：**
1. **必有常數項 $+1$**（否則可被 $x$ 整除，淘汰 4 個）：
   -  $x^3$
   -  $x^3+x$ 
   -  $x^3+x^2$ 
   -  $x^3+x^2+x$
2. **總項數必為奇數**（否則代 $x=1$ 為 $0$，可被 $x+1$ 整除，淘汰 2 個）：
   -  $x^3+1 = (x+1)(x^2+x+1)$
   -  $x^3+x^2+x+1 = (x+1)^3$

**僅剩 2 個不可約多項式**：$x^3 + x + 1$、**$x^3 + x^2 + 1$**（以下範例選用）

---

## $GF(2^3)$ 乘法範例：`111` $\times$ `111`

設定模數 $m(x) = x^3 + x^2 + 1 \;\Longrightarrow\;$ 降次規則 **$x^3 \equiv x^2 + 1$**

計算 $(x^2 + x + 1) \times (x^2 + x + 1)$：

1. **多項式展開**：
   $$x^4 + 2x^3 + 3x^2 + 2x + 1$$
2. **係數 $\bmod 2$**：
   $$x^4 + x^2 + 1$$
3. **降次代換**（遇到 $x^3$ 就換成 $x^2 + 1$）：
   $$x(x^3) + x^2 + 1 \equiv x(x^2 + 1) + x^2 + 1 = x^3 + x^2 + x + 1$$
   $$(x^2 + 1) + x^2 + x + 1 \equiv x$$

**結果**：`111` $\times$ `111` $=$ `010`（十進位 $7 \times 7 = 2$，成功壓回 3 Bits）
