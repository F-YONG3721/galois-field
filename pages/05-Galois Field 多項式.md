### $GF(p^n)$
#### $GF(p^n)$的簡介
除了質數以外， $p^n$ 也可以形成Galois Field，但不是用整數的方式去計算。在這裡需要引入一個多項式基底(polynomial basis)的概念。

#### 為什麼要使用多項式基底？

在 $GF(p^n)$ 中，我們不再使用一般整數，而是將元素表示為以 $x$ 為變數的**多項式**。對於 $GF(2^n)$ 來說，它的任何一個元素都可以寫成以下的「多項式基底」組合：

$A(x) = a_{n-1}x^{n-1} + a_{n-2}x^{n-2} + \dots + a_1x + a_0$

這裡有兩個關鍵的設計，讓它能完美對應到電腦底層架構：

1. **最高次方只到 $n-1$：** 剛好對應電腦記憶體中的 $n$ 個位元（從第 $0$ 到第 $n-1$ 位元）。
2. **係數只能是 $0$ 或 $1$：** 因為這是建立在 $GF(2)$ 基礎上的擴充體，多項式的各項係數 $a_i$ 先天上被定義只能是 $0$ 或 $1$。

**整數與多項式的對應：**
正因為係數只有 $0$ 與 $1$，我們可以將多項式的係數直接看作電腦中的二進位 Bits。
以 $GF(2^8)$ 空間中的多項式 $x^6 + x^4 + x + 1$ 為例，補齊 8 個項次後，提取係數即可得到：
`01010011`

這組二進位字串轉換成十進位就是 `83`（十六進位 `0x53`）。這也是為什麼在程式實作時，我們表面上是在對整數進行 `mod 2` 或是 XOR 位元運算，但在密碼學的數學本質上，我們其實是在處理這些多項式的加減法。

### $GF(2^n)$ 多項式運算規則與三步驟

在 $GF(2^n)$ 中，每一個元素佔用 $n$ 個 Bits，並被視為最高次方小於 $n$（Degree $\lt n$）的多項式。為了確保運算結果永遠落在這 $n$ 個 Bits 的範圍內（封閉性）且每個非零元素都有乘法反元素，乘法運算必須遵循以下**三個核心步驟**：

1. **多項式展開**：依照一般乘法分配律將兩多項式乘開。
2. **係數對 2 取餘數 (Coefficients Modulo 2)**：解決「**係數太大**」的問題。將同次方項的係數進行 $\bmod 2$ 運算（偶數抵銷為 `0`、奇數保留為 `1`，等同於二進位的 XOR 運算）。
3. **對不可約多項式取餘數 (Modulo an Irreducible Polynomial)**：解決「**次方溢位**」的問題。若運算後最高次方 $\ge n$（超出 $n$ 個 Bits 能表示的範圍），則必須將整個多項式除以一個預先選定的 $n$ 次不可約多項式 $m(x)$ 並取其餘數，強制將次方壓回 $< n$。

---

#### 三步驟詳細說明：與傳統多項式計算的差異

以下我們以 **$GF(2^3)$** 為例 $p=2, n=3$ ，每個數字固定佔 **3 個 Bits**，集合共有 $2^3 = 8$ 種不同的組合），並選用不可約多項式 **$m(x) = x^3 + x^2 + 1$**。
為了明顯看出「係數超過 1」與「次方超過 3 Bits 邊界」的變化，我們以計算 **`111` $\times$ `111`（即 $7 \times 7$）** 為例，對應的多項式為 **$(x^2 + x + 1) \times (x^2 + x + 1)$**：

##### 第一步：多項式展開
- **傳統多項式計算**：利用乘法分配律將每一項逐一乘開：
  $$(x^2 + x + 1)(x^2 + x + 1) = x^4 + (x^3 + x^3) + (x^2 + x^2 + x^2) + (x + x) + 1$$
- **$GF(2^3)$ 計算方式**：這一步與傳統數學**完全相同**。但請注意，展開後出現了多個重複的同次項，且最高次方衝到了 $x^4$（$x^2 \times x^2 = x^4$）。

##### 第二步：係數對 2 取餘數 (解決「係數超過 1」的問題)
- **傳統多項式計算**：同次方項的係數直接相加，**傳統多項式計算到這一步就結束了**，最終答案為：
  $$x^4 + (1+1)x^3 + (1+1+1)x^2 + (1+1)x + 1 = x^4 + 2x^3 + 3x^2 + 2x + 1$$
- **$GF(2^3)$ 計算方式（差異點 1：偶數抵銷、奇數保留）**：
  因為電腦的每個 Bit 只能存 `0` 或 `1`（處於 $GF(2)$），裝不下 $2$ 或 $3$ 這種係數。因此所有累加後的係數都必須 $\bmod 2$（偶數變 $0$、奇數變 $1$）：
  $$x^4 + (2 \bmod 2)x^3 + (3 \bmod 2)x^2 + (2 \bmod 2)x + 1 = 1x^4 + 0x^3 + 1x^2 + 0x + 1 = x^4 + x^2 + 1$$
  > **注意**：做完係數 $\bmod 2$ 後，$1x^4$ 的係數 $1 \bmod 2$ 依然是 $1$！這代表**單靠係數取餘數，無法消滅 $x^4$**，因此必須進入第三步。

##### 第三步：對不可約多項式 $m(x)$ 取餘數 (解決「次方溢位」的問題)
- **傳統多項式計算**：無此步驟，直接保留 $x^4$。
- **$GF(2^3)$ 計算方式（差異點 2：將次方壓回 3 Bits 內）**：
  1. **為什麼 $x^4$ 算溢位？為什麼次方一定要 $< 3$？**
     在 $GF(2^3)$ 中，每個元素只有 **3 個 Bits** 的空間，由左到右分別代表 $x^2, x^1, x^0$（最高只能裝到 $x^2$，即次方 $< 3$）。現在算出了 $x^4$，相當於需要第 5 個 Bit 才能存放，發生了**位元溢位 (Overflow)**。
  2. **$m(x)$ 的定義是什麼？怎麼來的？**
     $m(x)$ 稱為**不可約多項式 (Irreducible Polynomial)**，定義為「無法被因式分解成兩個較低次方多項式相乘的多項式」，角色就如同整數中的**質數**。在 $GF(2^3)$ 中，3 次的不可約多項式只有兩個：$x^3 + x + 1$ 與 $x^3 + x^2 + 1$。我們預先選定 **$m(x) = x^3 + x^2 + 1$** 當作全系統的「標準除數（模數）」。
#### 如何找出 $GF(2^3)$ 的不可約多項式 $m(x)$？

在 $GF(2^3)$ 中，為了將餘數剛好限制在 3 個 Bits（最高到 $x^2$），除數 $m(x)$ 的最高次方必須固定為 **$x^3$**，且必須像質數一樣**無法被因式分解**。我們可以透過以下三步驟篩選出來：

**第一步：列出所有最高為 $x^3$ 的多項式（共 $2^3 = 8$ 種可能）**
剩下的 $x^2, x, 1$ 三個位置各有「有 ($1$)」或「無 ($0$)」兩種狀態，共有 8 個候選者：
$x^3$、$x^3+x$、$x^3+x^2$、$x^3+x^2+x$、$x^3+1$、$x^3+x^2+x+1$、$x^3+x+1$、$x^3+x^2+1$

**第二步：用兩個簡單的規則把「可分解（合數）」的淘汰掉**
* **規則一：結尾沒有常數項 $+1$ 的全部淘汰（因為可以被 $x$ 整除）**
  這就像十進位的偶數一定能被 $2$ 整除一樣。如果最後面沒有 $+1$，每一項都至少有一個 $x$，可以直接把 $x$ 提出來（代 $x=0$ 會等於 $0$）：
  * $x^3 = x \cdot x^2$ （淘汰）
  * $x^3 + x = x(x^2 + 1)$ （淘汰）
  * $x^3 + x^2 = x(x^2 + x)$ （淘汰）
  * $x^3 + x^2 + x = x(x^2 + x + 1)$ （淘汰）
* **規則二：總項數是「偶數個」的全部淘汰（因為可以被 $x+1$ 整除）**
  在 $GF(2)$ 裡，如果把 $x = 1$ 代入多項式，每一個有 $x$ 的項都會變成 $1$。如果總共有**偶數個項**，全部的 $1$ 加起來 $\bmod 2$ 就會剛好抵銷變成 $0$！根據因式定理，代入 $1$ 等於 $0$，代表它一定可以被 $(x+1)$ 整除：
  * $x^3 + 1$ （共 2 項，代 $x=1$ 得 $1+1=0$，可分解為 $(x+1)(x^2+x+1)$，淘汰）
  * $x^3 + x^2 + x + 1$ （共 4 項，代 $x=1$ 得 $1+1+1+1=0$，可分解為 $(x+1)^3$，淘汰）

**第三步：剩下的就是不可約多項式 $m(x)$！**
扣掉上面 6 個可分解的多項式後，全世界 3 次的不可約多項式就只剩下最後這 **2 個**（它們代 $x=0$ 或 $x=1$ 都不會是 $0$，無法被任何一次式整除）：
1. **$m(x) = x^3 + x + 1$**
2. **$m(x) = x^3 + x^2 + 1$** （我們在下方範例選用的標準模數）

  3. **為什麼除以 $m(x)$ 取餘數就能保證壓回 3 Bits？**
     根據多項式長除法規則，**「餘式的最高次方」必定嚴格小於「除式的最高次方」**。因為除式 $m(x)$ 是 **$3$ 次方 ($x^3$)**，所以不管被除式是 $x^4$ 還是更高次方，除完剩下的**餘數最高次方一定 $< 3$**（最多只到 $x^2$），保證能塞回 3 個 Bits！
  4. **實際取餘數過程**：
     計算 $(x^4 + x^2 + 1) \div (x^3 + x^2 + 1)$ 的餘數（在 $GF(2)$ 中減法與加法皆為 XOR $\oplus$）：
     - **方法 A（多項式長除法）**：
       - 第一輪（消去 $x^4$）：將除式乘上 $x$ 得到 $x^4 + x^3 + x$，與原式相減（XOR）：
         $$(x^4 + x^2 + 1) \oplus (x^4 + x^3 + x) = x^3 + x^2 + x + 1$$
       - 第二輪（消去剩下的 $x^3$）：將除式乘上 $1$ 得到 $x^3 + x^2 + 1$，再相減（XOR）：
         $$(x^3 + x^2 + x + 1) \oplus (x^3 + x^2 + 1) = x$$
     - **方法 B（快速降次代換法）**：
       令除式 $x^3 + x^2 + 1 \equiv 0$，移項可得降次公式 **$x^3 \equiv x^2 + 1$**（每當遇到 $x^3$ 就換成 $x^2 + 1$）：
       $$x^4 + x^2 + 1 = x(x^3) + x^2 + 1 = x(x^2 + 1) + x^2 + 1 = x^3 + x^2 + x + 1$$
       再將剩下的 $x^3$ 代換為 $x^2 + 1$（相同項兩兩抵銷）：
       $$(x^2 + 1) + x^2 + x + 1 = (1+1)x^2 + x + (1+1) = x$$
  - **最終結果**：$(x^2 + x + 1) \times (x^2 + x + 1) = x$（對應二進位 `111` $\times$ `111` $=$ `010`，即十進位的 $7 \times 7 = 2$，完美壓回 3 個 Bits 內！）。
