### 1. 什麼是體 (Field)？
- 一個有限集合，同時定義**加法**與**乘法**
- 運算結果永遠留在集合內（**封閉性**）
- 每個非零元素皆存在唯一**乘法反元素**（可做除法、可 100% 還原）

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4">

### 2. 常數與多項式
- **常數 $GF(p)$**：整數 $\bmod$ 質數 $p$（如 $GF(7)$）
- **多項式 $GF(2^n)$**：$n$ 個 Bits 直接對應 $n-1$ 次多項式，係數只能是 `0` 或 `1`
- 係數 $\bmod 2$：加減法完全等同 **XOR ($\oplus$)**

</div>

<div class="bg-white/5 border border-amber-400/40 rounded-xl p-4">

### 3. 如果 Overflow 怎麼辦？
- 乘法產生最高次方 $\ge n$（超出 $n$ Bits 邊界）時發生 **Overflow**
- 解法：除以預先選定的 $n$ 次**不可約多項式 $m(x)$** 取餘數
- 餘式次方必定 $< n$，完美壓回固定位寬內

</div>

</div>

## 為什麼要改用查表法？

直接照數學定義寫程式太慢，我們需要更快的做法：

<div class="grid grid-cols-2 gap-5 mt-4 text-sm">

<div class="bg-white/5 border border-red-400/40 rounded-xl p-4 space-y-2.5">

### 1. 一般做法（直接硬算）
- **怎麼算**：每次遇到兩個多項式相乘，都當場跑雙層迴圈「逐項乘開 ＋ 長除法取餘數」。
- **時間複雜度**：單次乘法就要 **$O(n^2)$**（就算改用二進位左移也要跑 $O(n)$ 迴圈）。
- **問題**：太慢了！加密一個檔案要算上億次乘法，每次都重跑迴圈會嚴重拖垮效能。

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4 space-y-2.5">

### 2. 我們的解決方法（預先建表 ＋ 查表法）
- **怎麼做**：程式剛啟動時，先用 **Shift + XOR** 把所有可能的結果算過一輪，存進陣列當作「字典」。
- **為什麼比較快**：建表**只做 1 次**；之後上億次運算都不用再跑迴圈，直接打開陣列查答案＋做整數加減就好！
- **時間複雜度**：單次運算直接降為 **$O(1)$**（固定時間，最快！）。

</div>

</div>

<div class="mt-4 bg-white/5 border border-white/10 rounded-xl px-4 py-2.5 text-center text-sm">
💡 <b>接下來的實作步驟</b>：先認識建表用的 <b>Shift + XOR</b> 怎麼算 $\;\longrightarrow\;$ 再用它寫出 <b>$O(1)$ 查表程式碼</b>！

## $GF(2^8)$ 二進位乘法：Shift + XOR 計算方式

把「乘上 $x$」寫成二進位左移 1 位：若左移前最高位 $b_7 = 1$，左移後**第 9 個 bit（$x^8$）就會變成 `1` 溢位**，此時 XOR 不可約多項式即可同時消掉第 9 bit 並完成降次：

$$x \times f(x) = \begin{cases} (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) & \text{if } b_7 = 0 \text{（第 9 bit 為 0，未溢位）} \\ (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) \oplus (00011011) & \text{if } b_7 = 1 \text{（第 9 bit 為 1，XOR 模數降次）} \end{cases}$$

<div class="grid grid-cols-12 gap-4 mt-2 text-xs">
<div class="col-span-7 bg-white/5 border border-white/10 rounded-lg p-3 font-mono space-y-0.5">
  <div class="font-sans font-bold text-sky-400 mb-1">經典範例：f = 01010111 × g = 10000011，模 0x11B</div>
  <div><span class="text-emerald-400">x⁰·f</span> = 01010111 <span class="text-emerald-400">← 選取 (g 第 0 位=1)</span></div>
  <div><span class="text-emerald-400">x¹·f</span> = <span class="opacity-60">0</span>|10101110 <span class="text-emerald-400">← 選取 (g 第 1 位=1)</span></div>
  <div>x²·f = <span class="text-red-300 font-bold">1</span>|01011100 ⊕ <span class="text-amber-300">1|00011011</span> = 01000111</div>
  <div>x³·f = <span class="opacity-60">0</span>|10001110</div>
  <div>x⁴·f = <span class="text-red-300 font-bold">1</span>|00011100 ⊕ <span class="text-amber-300">1|00011011</span> = 00000111</div>
  <div>x⁵·f = 00001110　｜　x⁶·f = 00011100</div>
  <div><span class="text-emerald-400">x⁷·f</span> = <span class="opacity-60">0</span>|00111000 <span class="text-emerald-400">← 選取 (g 第 7 位=1)</span></div>
</div>

  <div class="text-[11px] opacity-85">
    因為乘數 <code>g = 10000011</code> 就是 x<sup>7</sup> + x<sup>1</sup> + 1，<br/>
    由<b>分配律</b> f × (x<sup>7</sup> + x + 1) 把這三項相加（XOR）：
  </div>

    <div>⊕ 10101110 (x¹·f)</div>
    <div>⊕ 00111000 (x⁷·f)</div>
    <div class="border-t border-white/20 pt-1 text-emerald-300 font-bold text-sm">= 11000001 (x<sup>7</sup>+x<sup>6</sup>+1)</div>

## 查表法原理：把「乘除法」變成「次方數加減」

用國中學過的指數律 **$2^1 \times 2^2 = 2^{1+2} = 2^3$** 來想，原本麻煩的乘法，只要換成**次方數**就變成簡單的**加法**！

<div class="grid grid-cols-12 gap-4 mt-3 text-xs">
<div class="col-span-5 space-y-2.5 text-sm">

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-3.5">

**1. 建兩張反查字典（啟動時做 1 次）**
- **`exp_table[次方] = 數字`**  
  例：`exp[1] = 2`、`exp[2] = 4`、`exp[3] = 8`
- **`log_table[數字] = 次方`**  
  例：`log[2] = 1`、`log[4] = 2`、`log[8] = 3`

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-3.5 text-xs leading-relaxed">
<b>舉例算 <code>2 × 4</code>：</b><br/>
① 查次方：<code>log[2] = 1</code>、<code>log[4] = 2</code><br/>
② 次方相加：<code>1 + 2 = 3</code><br/>
③ 查回數字：<code>exp[3] = <b>8</b></code>（不用跑迴圈！）
</div>

</div>
<div class="col-span-7 bg-white/5 border border-white/10 rounded-xl p-3.5 [&_th]:!py-1.5 [&_td]:!py-1.5">

**2. 查表公式速查（$GF(2^3)$ 週期 $M=7$；$GF(2^8)$ 週期 $M=255$）**

| 運算 | 查表做法 | 程式碼寫法 |
|:---:|:---|:---|
| **加／減** | 直接位元 XOR | `a ^ b` |
| **乘法** | 次方**相加** $\to$ 查回數字 | `exp[(log[a] + log[b]) % M]` |
| **除法** | 次方**相減** $\to$ 查回數字 | `exp[(log[a] - log[b] + M) % M]` |
| **反元素** | 用 $M$ **減次方** $\to$ 查回數字 | `exp[M - log[a]]` |

<div class="mt-2 pt-2 border-t border-white/15 text-[11px] opacity-85">
⚠ <b>兩個小防呆</b>：① 遇到 <code>0</code> 直接回傳 <code>0</code>（0 沒有次方數）　② 建表結尾補上 <code>exp[M] = 1</code>（讓 <code>inv(1)</code> 查 <code>exp[M-0]</code> 等於 1）。
</div>

</div>

## 程式實作（一）：$GF(2^3)$ C++ 實作（$M = 7$）

先以 3-bit 的 **$GF(2^3)$**（本原多項式 $x^3 + x^2 + 1 =$ `0b1101`，非零週期 $M = 2^3 - 1 = 7$）驗證查表架構：

<div class="grid grid-cols-12 gap-4 items-start mt-2">
<div class="col-span-7">

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

class GF8 {
private:
    int exp_table[8]; // 次方數 -> 係數 (1~7)
    int log_table[8]; // 係數 (1~7) -> 次方數

public:
    GF8() {
        int poly = 0b1101; // x^3 + x^2 + 1
        int val = 1;

        for (int i = 0; i < 7; i++) {
            exp_table[i] = val;
            log_table[val] = i;

            val = val << 1;     // 乘上生成元 g = 2 (x)
            if (val >= 8) {     // 第 4 bit 為 1 (出現 x^3 溢位)
                val ^= poly;    // XOR 0b1101 壓回 3 Bits
            }
        }
        exp_table[7] = 1;       // 補上 g^7 = 1，確保 inv(1) 正確
    }

    int add(int a, int b) { return a ^ b; }
    int sub(int a, int b) { return a ^ b; }

    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] + log_table[b]) % 7];
    }

    int div(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] - log_table[b] + 7) % 7];
    }

    int inv(int a) {
        if (a == 0) return 0;
        return exp_table[7 - log_table[a]];
    }
};
```

</div>
<div class="col-span-5 text-xs space-y-2.5">

<div class="bg-white/5 border border-white/10 rounded-lg p-2.5 [&_th]:!py-0.5 [&_td]:!py-0.5">

**建出的完整 7 格對照表**

| 次方 `i` | `0` | `1` | `2` | `3` | `4` | `5` | `6` |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **`exp[i]`** | 1 | 2 | 4 | 5 | 7 | 3 | 6 |

</div>

<div class="bg-emerald-500/10 border border-emerald-400/40 rounded-lg p-3 space-y-1.5">
  <div class="font-bold text-emerald-400">對照第 05 章手算結果：</div>
  <div>• <b>乘法 <code>mul(7, 7)</code></b>：<br/><code>log[7] = 4</code> → <code>(4+4) % 7 = 1</code> → <code>exp[1] = <b>2</b></code> ✓</div>
  <div>• <b>反元素 <code>inv(7)</code></b>：<br/><code>exp[7 - 4]</code> = <code>exp[3] = <b>5</b></code>（<code>x²+1</code>）✓</div>

## 程式實作（二）：$GF(2^8)$ C++ 實作（$M = 255$）

把架構完全不變地放大到 **1 Byte（8 Bits）**：陣列改為 `256`、溢位門檻改為 `256`、模數換成 `0x11D`、週期改為 `255`，就是真實工程使用的 $GF(2^8)$：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

class GF256 {
private:
    int exp_table[256]; // 次方數 -> 係數 (數值)
    int log_table[256]; // 係數 (數值) -> 次方數

public:
    // 建構子：初始化並建立查表陣列
    GF256() {
        int poly = 0x11D; // 本原多項式 x^8 + x^4 + x^3 + x^2 + 1
        int val = 1;      // 從 g^0 = 1 開始

        // 依序產生 1~255 全部 255 個非零元素
        for (int i = 0; i < 255; i++) {
            exp_table[i] = val; // 紀錄次方數對應的係數
            log_table[val] = i; // 紀錄係數反查的次方數

            val = val << 1;     // 左移 1 位 = 乘上生成元 g = 2 (x)
            if (val >= 256) {   // 第 9 bit 為 1 (出現 x^8) 代表溢位
                val ^= poly;    // XOR 0x11D 降次，壓回 1 Byte 內
            }
        }
        exp_table[255] = 1;     // 補上 g^255 = 1，確保 inv(1) 正確
    }

    // 加法：無進位 XOR
    int add(int a, int b) {
        return a ^ b;
    }

    // 減法：係數 mod 2 下與加法相同
    int sub(int a, int b) {
        return a ^ b;
    }

    // 乘法：次方數相加 (mod 255) 再查回係數
    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0; // 0 沒有對應的次方數
        return exp_table[(log_table[a] + log_table[b]) % 255];
    }

    // 除法：次方數相減 (加 255 避免負數) 再查回係數
    int div(int a, int b) {
        if (a == 0 || b == 0) return 0; // 避免 0 或除以 0
        return exp_table[(log_table[a] - log_table[b] + 255) % 255];
    }

    // 乘法反元素：用 255 減掉次方數再查回係數
    int inv(int a) {
        if (a == 0) return 0; // 0 沒有乘法反元素
        return exp_table[255 - log_table[a]];
    }
};
```
