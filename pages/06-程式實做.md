## 程式實作：$GF(2^8)$ 查表法原理

<div class="grid grid-cols-2 gap-4 mt-3 text-sm">

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**① 為什麼要用查表法？（空間換時間）**  
直接做多項式展開與長除法需要跑迴圈，處理海量 Byte 太慢；預先建表即可將運算降為 **$O(1)$** 陣列讀取。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**② 關鍵數學：生成元 $g = 3$ ($x+1$)**  
在 AES 模數 `0x11B` 下，$g=2$ 週期只有 51 會提早循環；改用生成元 **$g=3$**，連乘 $g^0 \sim g^{254}$ 剛好不重複走遍所有 255 個非零元素。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**③ 兩張表互為反函數**  
- **`exp_table[i]`** $= g^i$（給指數 $i \to$ 查元素值）  
- **`log_table[x]`** $= i$（給元素值 $x \to$ 反查指數）

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**④ 乘法變加法、反元素變減法**  
- 乘法：$a \times b = g^{(\log(a)+\log(b)) \bmod 255}$  
- 反元素：$a^{-1} = g^{255 - \log(a)}$

</div>

</div>

### 1. 建表實作：一步步生成 `exp_table` 與 `log_table`

<div class="grid grid-cols-12 gap-5 items-start mt-2">
<div class="col-span-7">

```cpp {1-2|4-7|9-12|14}
const int poly = 0x11B;             // AES 不可約多項式
int exp_table[256], log_table[256]; // 宣告兩張查表陣列

int x = 1;
for (int i = 0; i < 255; ++i) {
    exp_table[i] = x;               // 指數 i -> 元素值 x
    log_table[x] = i;               // 元素值 x -> 指數 i

    // 乘上生成元 g = 3 (x + 1)：(x * 2) XOR x
    int x2 = x << 1;                // 左移 1 位 = 乘以 x (2)
    if (x2 & 256) x2 ^= poly;       // 第 9 bit 溢位就 XOR 0x11B
    x = x2 ^ x;                     // 再 XOR 原本的 x = 乘 3
}
exp_table[255] = 1;                 // 補上 g^255 = 1 (修正 inverse(1))
```

</div>
<div class="col-span-5 text-xs space-y-2">

<div class="bg-white/5 border border-sky-400/40 rounded-lg p-2.5">
  <div class="font-bold text-sky-400">Step 1：設定模數與陣列</div>
  選定 AES 標準 <code>0x11B</code>（x<sup>8</sup>+x<sup>4</sup>+x<sup>3</sup>+x+1），準備 256 格的指數表與對數表。
</div>

<div v-click="1" class="bg-white/5 border border-emerald-400/40 rounded-lg p-2.5">
  <div class="font-bold text-emerald-400">Step 2：同步寫入雙表（前 4 步）</div>
  <div class="mt-1 font-mono space-y-0.5">
    <div>i=0 → exp[0]=<b>1</b>,  log[1]=<b>0</b></div>
    <div>i=1 → exp[1]=<b>3</b>,  log[3]=<b>1</b></div>
    <div>i=2 → exp[2]=<b>5</b>,  log[5]=<b>2</b></div>
    <div>i=3 → exp[3]=<b>15</b>, log[15]=<b>3</b></div>
  </div>
</div>

<div v-click="2" class="bg-amber-500/15 border border-amber-400/40 rounded-lg p-2.5 text-amber-200">
  <div class="font-bold text-amber-300">Step 3：乘 3 ＆ 溢位降次（i = 8）</div>
  <code>x = 255</code> → <code>x2 = 255 &lt;&lt; 1 = 510</code>（溢位！）<br/>
  <code>510 ^ 0x11B = 229</code> → <code>229 ^ 255 = <b>26</b></code>
</div>

<div v-click="3" class="bg-white/5 border border-pink-400/40 rounded-lg p-2.5">
  <div class="font-bold text-pink-400">Step 4：補齊邊界條件</div>
  <code>exp[255] = 1</code>，確保 <code>inverse(1)</code> 查 <code>exp[255 - 0]</code> 正確回傳 <b>1</b>。
</div>

### 2. $O(1)$ 四則與反元素實作（點按同步對照）

<div class="grid grid-cols-12 gap-5 items-start mt-2">
<div class="col-span-7">

```cpp {1-4|6-10|12-16}
// 1. 加減法：無進位 XOR
int add(int a, int b) {
    return a ^ b;
}

// 2. 乘法：查 log 相加 → 查 exp
int multiply(int a, int b) {
    if (a == 0 || b == 0) return 0;
    return exp_table[(log_table[a] + log_table[b]) % 255];
}

// 3. 乘法反元素：AES S-Box 核心
int inverse(int a) {
    if (a == 0) return 0;
    return exp_table[255 - log_table[a]];
}
```

</div>
<div class="col-span-5 text-xs space-y-2.5">

<div class="bg-white/5 border border-sky-400/40 rounded-lg p-3">
  <div class="font-bold text-sky-400 mb-1">Step 1：加法 add(3, 5)</div>
  <div><code>3 = 0000 0011</code>、<code>5 = 0000 0101</code></div>
  <div class="text-emerald-400 font-bold mt-0.5">XOR 結果 = <code>0000 0110</code> = <b>6</b> ✓</div>
</div>

<div v-click="1" class="bg-white/5 border border-emerald-400/40 rounded-lg p-3">
  <div class="font-bold text-emerald-400 mb-1">Step 2：乘法 multiply(3, 5)</div>
  <div>① 查對數：<code>log[3] = 1</code>、<code>log[5] = 2</code></div>
  <div>② 指數相加：<code>(1 + 2) % 255 = 3</code></div>
  <div class="text-emerald-400 font-bold mt-0.5">③ 查指數：<code>exp[3] = <b>15</b></code> ✓</div>

  <div>① 查對數：<code>log[3] = 1</code></div>
  <div>② 互補指數：<code>255 - 1 = 254</code></div>
  <div class="text-emerald-400 font-bold mt-0.5">③ 查指數：<code>exp[254] = <b>246</b></code>（<code>3 × 246 = 1</code>）✓</div>

### 進入真實世界：為什麼是 $GF(2^8)$ ？

前面我們利用 $GF(2^3)$ 徹底理解了多項式的 XOR 抵銷與降次代換。但回到真實的計算機科學領域，我們最需要也最常使用的，是 **$GF(2^8)$**。

#### 1. 什麼時候會發生溢位 (Overflow)？
在 $GF(2^8)$ 的空間中，一個元素剛好對應電腦底層的 **1 Byte (8 Bits)**。
這 8 個 Bits 能表示的最高次方是 **$x^7$**（例如二進位 `11111111` $= x^7+x^6+...+1$）。

* **觸發溢位的瞬間**：當我們進行乘法運算時，只要產生了 **$x^8$ 或更高的次方**，就代表需要「第 9 個 Bit」才能儲存，這在 8-bit 的資料結構中就會發生 Overflow。
* **解決方案**：一旦偵測到 $x^8$ 出現，系統就會立刻除以 8 次的不可約多項式 $m(x)$ ，透過 XOR 取餘數，將超出邊界的次方完美壓回 1 Byte 的空間內，保證資料永遠不會因溢位而遺失或失真。

---
---
#### 2. 從 $GF(2^3)$ 到 $GF(2^8)$ 的根本差異
推廣到 8 次方後，數學運算規則（加減法等於 XOR、找質式降次）完全沒有改變，真正的差異在於**工程上的意義**：
* **$GF(2^3)$**：空間太小（只有 8 種變化），只能作為數學課堂上的概念模型。
* **$GF(2^8)$**：空間剛好是 256 種變化，完美對應 ASCII 碼、像素顏色 (0~255)、以及記憶體中的任何一個 Byte。**我們把電腦裡所有的 Byte，都變成了可以做嚴格代數運算的數學實體。**
