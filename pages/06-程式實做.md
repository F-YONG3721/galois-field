### 進入真實世界：為什麼是 $GF(2^8)$ ？

前面我們利用 $GF(2^3)$ 徹底理解了多項式的 XOR 抵銷與降次代換。但回到真實的計算機科學領域，我們最需要也最常使用的，是 **$GF(2^8)$**。

#### 1. 什麼時候會發生溢位 (Overflow)？
在 $GF(2^8)$ 的空間中，一個元素剛好對應電腦底層的 **1 Byte (8 Bits)**。
這 8 個 Bits 能表示的最高次方是 **$x^7$**（例如二進位 `11111111` $= x^7+x^6+...+1$）。

* **觸發溢位的瞬間**：當我們進行乘法運算時，只要產生了 **$x^8$ 或更高的次方**，就代表需要「第 9 個 Bit」才能儲存，這在 8-bit 的資料結構中就會發生 Overflow。
* **解決方案**：一旦偵測到 $x^8$ 出現，系統就會立刻除以 8 次的不可約多項式 $m(x)$ ，透過 XOR 取餘數，將超出邊界的次方完美壓回 1 Byte 的空間內，保證資料永遠不會因溢位而遺失或失真。

---
---
#### 2. 從 $GF(2^3)$ 到 $GF(2^8)$ 的根本差異
推廣到 8 次方後，數學運算規則（加減法等於 XOR、不可約多項式降次）完全沒有改變，真正的差異在於**工程上的意義**：
* **$GF(2^3)$**：空間太小（只有 8 種變化），只能作為數學課堂上的概念模型。
* **$GF(2^8)$**：空間剛好是 256 種變化，完美對應 ASCII 碼、像素顏色 (0~255)、以及記憶體中的任何一個 Byte。**我們把電腦裡所有的 Byte，都變成了可以做嚴格代數運算的數學實體。**

<div class="mt-4 bg-white/5 border border-white/10 rounded-lg px-4 py-2 text-sm [&_th]:!py-1.5 [&_td]:!py-1.5">

| 比較項目 | $GF(2^3)$（教學模型） | $GF(2^8)$（工程標準） |
|:---:|:---:|:---:|
| **位元寬度** | 3 Bits | **8 Bits（1 Byte）** |
| **元素總數** | $2^3 = 8$（`0`～`7`） | **$2^8 = 256$（`0`～`255`）** |
| **最高次方** | $x^2$（出現 $x^3$ 溢位） | **$x^7$（出現 $x^8$ 溢位）** |
| **常用模數 $m(x)$** | $x^3 + x^2 + 1$ | **$x^8+x^4+x^3+x^2+1$（`0x11D`）** |
| **實際用途** | 課堂手算與觀念理解 | **AES 加密、QR Code / Reed-Solomon 糾錯碼** |

</div>

## 程式實作：$GF(2^8)$ 查表法原理

<div class="grid grid-cols-2 gap-4 mt-3 text-sm">

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**① 為什麼要用查表法？（空間換時間）**  
直接做多項式展開與長除法需要跑迴圈，處理海量 Byte 太慢；預先建表即可將運算降為 **$O(1)$** 陣列讀取。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**② 關鍵數學：本原多項式 `0x11D` 與生成元 $g = 2$ ($x$)**  
選用 `0b100011101`（$x^8+x^4+x^3+x^2+1$，QR Code 標準），生成元直接用 **$g = 2$**（左移 1 位 `<< 1`），連乘 $g^0 \sim g^{254}$ 剛好不重複走遍全部 255 個非零元素。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**③ 兩張表互相對照（次方數 $\leftrightarrow$ 係數）**  
- **`exp_table[次方數]`**：給**次方數** $\to$ 查出對應的**係數（數值）**  
- **`log_table[係數]`**：給**係數（數值）** $\to$ 反查出對應的**次方數**

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**④ 乘法變「次方數相加」、反元素變「次方數相減」**  
- **乘法**：查出兩數的**次方數** $\to$ **相加**（$\bmod 255$）$\to$ 查回係數  
- **反元素**：用 `255` **減掉**它的**次方數** $\to$ 查回係數（因 $g^{255}=1$）

</div>

</div>

### C++ 實作程式碼（$GF(2^8)$）

```cpp {lines:true, maxHeight:'410px'}
#include <iostream>
using namespace std;

class GF256 {
private:
    int exp_table[256];
    int log_table[256];

public:
    GF256() {
        int poly = 0x11D; // x^8 + x^4 + x^3 + x^2 + 1
        int val = 1;

        for (int i = 0; i < 255; i++) {
            exp_table[i] = val;
            log_table[val] = i;

            val = val << 1;
            if (val >= 256) {
                val ^= poly;
            }
        }
        exp_table[255] = 1;
    }

    int add(int a, int b) {
        return a ^ b;
    }

    int sub(int a, int b) {
        return a ^ b;
    }

    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] + log_table[b]) % 255];
    }

    int div(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] - log_table[b] + 255) % 255];
    }

    int inv(int a) {
        if (a == 0) return 0;
        return exp_table[255 - log_table[a]];
    }
};
```

### 核心位元運算解析：`val << 1` 與溢位降次

這三行程式碼就是把「**多項式乘上 $x$**」與「**除以 $m(x)$ 取餘數**」直接用 CPU 位元運算完成：

```cpp
val = val << 1;          // 1. 左移 1 位 = 多項式乘上 x (2)
if (val >= 256) {        // 2. 檢查是否超出 8 Bits (出現 x^8)
    val ^= poly;         // 3. XOR 0x11D 消去 x^8，壓回 1 Byte
}
```

<div class="grid grid-cols-2 gap-4 mt-3 text-xs">

<div class="bg-white/5 border border-emerald-400/40 rounded-lg p-3">

**情況 A：未溢位（例：`val = 4`）**
- 原本：`0000 0100`（$x^2$）
- 左移 `<< 1`：`0000 1000`（$x^3 = 8$）
- 結果 `8 < 256`，沒有超出 8 Bits，直接結束！

</div>

<div class="bg-amber-500/15 border border-amber-400/40 rounded-lg p-3">

**情況 B：觸發溢位（例：`val = 128`）**
- 原本：`1000 0000`（$x^7 = 128$）
- 左移 `<< 1`：**`1 0000 0000`**（$x^8 = 256 \ge 256$，溢位！）
- 立刻 XOR `0x11D`（`1 0001 1101`）：

```text
  1 0000 0000  (256 = x^8)
^ 1 0001 1101  (0x11D = x^8+x^4+x^3+x^2+1)
─────────────
  0 0001 1101  (29  = x^4+x^3+x^2+1)
```

</div>
