## 上週重點回顧

<div class="grid grid-cols-3 gap-4 mt-5 text-sm">

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-4">

### 1. 什麼是體 (Field)？
- 一個有限集合，同時定義**加法**與**乘法**
- 運算結果永遠留在集合內（**封閉性**）
- 每個非零元素皆存在唯一**乘法反元素**（可做除法、可 100% 還原）

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4">

### 2. 常數與多項式
- **常數 $GF(p)$**：整數 $\bmod$ 質數 $p$（如 $GF(7)$）
- **多項式 $GF(2^n)$**：$n$ 個 Bits 直接對應 $n-1$ 次多項式，係數只能是 `0` 或 `1`
- 係數 $\bmod 2$：加減法完全等同 **XOR ($\oplus$)**

</div>

<div class="bg-white/5 border border-amber-400/40 rounded-xl p-4">

### 3. 如果 Overflow 怎麼辦？
- 乘法產生最高次方 $\ge n$（超出 $n$ Bits 邊界）時發生 **Overflow**
- 解法：除以預先選定的 $n$ 次**不可約多項式 $m(x)$** 取餘數
- 餘式次方必定 $< n$，完美壓回固定位寬內

</div>

</div>

## 為什麼要改用查表法？

<div class="space-y-4 mt-4 text-sm">

<div class="bg-white/5 border border-red-400/40 rounded-xl p-4 space-y-1.5">

### 1. 一般做法：每次相乘都直接硬算（太慢）
- **怎麼算**：每次遇到兩個多項式相乘，都要當場跑雙層迴圈做「逐項展開 ＋ 長除法取餘數」，單次時間複雜度為 **$O(n^2)$**（就算改用二進位左移也要跑 $O(n)$ 迴圈）。
- **問題在哪**：加密一個檔案動輒要算**上億次**乘法，每次都重新跑迴圈會浪費大量 CPU 時間。

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4 space-y-1.5">

### 2. 解決方法：預先建表 ＋ $O(1)$ 查表法（空間換時間）
- **階段一（啟動時先把表建好，只算 1 次）**：程式剛啟動時，先用二進位 **Shift + XOR** 把所有非零數字與次方數的對應關係算過一輪，存進 `exp_table` 與 `log_table` 兩張字典。
- **階段二（實際算乘除時，翻字典把次方相加／相減）**：之後遇到 `A × B` 時**完全不用展開多項式**！只要查字典找出 `A`、`B` 各是第幾次方，把兩個次方數**直接做整數相加**（因為 $g^a \times g^b = g^{a+b}$），再查回對應的數字就是答案！
- **為什麼比較快**：建表只花極小的一次性成本（$GF(2^8)$ 僅 255 步），之後上億次運算通通**免跑迴圈**，單次時間複雜度降為 **$O(1)$**！

</div>

</div>

## $GF(2^8)$ 二進位乘法：Shift + XOR 計算方式

把「乘上 $x$」寫成二進位左移 1 位：若左移前最高位 $b_7 = 1$，左移後**第 9 個 bit（$x^8$）就會變成 `1` 溢位**，此時 XOR 不可約多項式即可同時消掉第 9 bit 並完成降次：

$$x \times f(x) = \begin{cases} (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) & \text{if } b_7 = 0 \text{（第 9 bit 為 0，未溢位）} \\ (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) \oplus (00011011) & \text{if } b_7 = 1 \text{（第 9 bit 為 1，XOR 模數降次）} \end{cases}$$

<div class="col-span-7 bg-white/5 border border-white/10 rounded-lg p-3 font-mono space-y-0.5">
  <div class="font-sans font-bold text-sky-400 mb-1">經典範例：f = 01010111 × g = 10000011，模 0x11B</div>
  <div><span class="text-emerald-400">x⁰·f</span> = 01010111 <span class="text-emerald-400">← 選取 (g 第 0 位=1)</span></div>
  <div><span class="text-emerald-400">x¹·f</span> = <span class="opacity-60">0</span>|10101110 <span class="text-emerald-400">← 選取 (g 第 1 位=1)</span></div>
  <div>x²·f = <span class="text-red-300 font-bold">1</span>|01011100 ⊕ <span class="text-amber-300">1|00011011</span> = 01000111</div>
  <div>x³·f = <span class="opacity-60">0</span>|10001110</div>
  <div>x⁴·f = <span class="text-red-300 font-bold">1</span>|00011100 ⊕ <span class="text-amber-300">1|00011011</span> = 00000111</div>

## 查表法原理（一）：`exp_table`（Exponential 指數表）

要理解查表法，先看每個符號**對應到 Galois Field 多項式裡的什麼東西**：

<div class="grid grid-cols-2 gap-4 mt-2.5 text-xs">

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-3 space-y-1">

**1. 什麼是生成元 $g$？（走路的步伐）**
- 選用本原多項式時，我們挑多項式 **$x$（二進位 `010`）** 當作固定步伐。
- 從 `001`（$1$）出發不斷乘上 $x$（左移＋溢位降次），剛好能像繞圓環一樣，**把全場全部 $2^n - 1$ 個非零多項式不重複地走過一遍**，最後繞回起點 `001`！

</div>

<div class="bg-white/5 border border-amber-400/40 rounded-xl p-3 space-y-1">

**2. 指數 $i$（走了幾步）—— 為什麼需要知道走了幾步？**
- 若多項式 $A = x^i$（從 `001` 走 $i$ 步）、多項式 $B = x^j$（走 $j$ 步）：
  $$A \times B = x^i \times x^j = x^{i+j}$$
- 原本複雜的多項式相乘，瞬間變成在圓環上 **「先走 $i$ 步、再走 $j$ 步 ＝ 總共走 $(i+j)$ 步」**！

</div>

</div>

<div class="bg-white/5 border border-white/15 rounded-xl p-3.5 mt-3 text-xs space-y-1">

**`exp_table` 定義：輸入「步數 $i$」$\longrightarrow$ 查出對應的「多項式二進位 $v$」**
- **作用**：當我們把步數加完後，靠它一秒查回「走這麼多步停在哪一個 GF 多項式上」。
- **例子（$GF(2^3)$）**：從 `001` 走 `4` 步會停在 `111`（$x^2+x+1$），所以 **`exp_table[4] = 111`**。

</div>

## 查表法原理（二）：`log_table`（Logarithm 對數表）

既然已經有 `exp_table` 記錄每一步走到哪個多項式，**為什麼還需要第二張表 `log_table`？**

<div class="space-y-3 mt-3 text-xs">

<div class="bg-white/5 border border-red-400/40 rounded-xl p-3.5 space-y-1">

**1. 沒有 `log_table` 會卡在哪裡？**
- 實際呼叫乘法 `mul(a, b)` 時，輸入進來的是**兩個多項式二進位 `a` 和 `b`**（例如 `101` 和 `111`），題目不會先告訴你它們各走了幾步！
- 如果沒有反查表，就必須重頭搜尋 `exp_table` 才能找出步數，又退化回跑迴圈了。

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-3.5 space-y-1">

**2. `log_table` 定義：輸入「多項式二進位 $v$」$\longrightarrow$ 反查「步數 $i$」**
- **作用**：直接回答「這個多項式是從 `001` 走了幾步才到的？」，建表時把 `exp_table` 索引與內容對調寫入即可（註：`000` 永遠走不到、沒有步數，遇到 `0` 直接回傳 `0`）。
- **例子（$GF(2^3)$）**：想知道 `111`（$x^2+x+1$）是走幾步到的，查 **`log_table[111] = 4`**，立刻得知是 `4` 步！

</div>

</div>

## 兩表合體：$O(1)$ 查表四則與反元素規則

令元素總數 `size` $= 2^n$（非零週期為 `size - 1`），四種運算都只需要一行：

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-4 space-y-2">

### 1. 加法 ／ 減法
- **做法**：係數 $\bmod 2$，直接位元互斥或（免查表）
- **程式碼**：`a ^ b`

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4 space-y-2">

### 2. 乘法 `mul(a, b)`
- **做法**：查 `log` 換步數 $\to$ **步數相加** $\to$ 查 `exp`
- **程式碼**：`exp_table[(log_table[a] + log_table[b]) % (size - 1)]`

</div>

<div class="bg-white/5 border border-amber-400/40 rounded-xl p-4 space-y-2">

### 3. 除法 `div(a, b)`
- **做法**：查 `log` 換步數 $\to$ **步數相減** $\to$ 查 `exp`
- **程式碼**：`exp_table[(log_table[a] - log_table[b] + size - 1) % (size - 1)]`

</div>

<div class="bg-white/5 border border-pink-400/40 rounded-xl p-4 space-y-2">

### 4. 乘法反元素 `inv(a)`
- **做法**：查 `log` 換步數 $\to$ **週期減步數** $\to$ 查 `exp`
- **程式碼**：`exp_table[(size - 1) - log_table[a]]`

</div>

</div>

## 程式實作（一）：$GF(2^3)$ C++ 實作

把剛才二進位演練的 **$GF(2^3)$**（元素總數 `8`、週期 `7`、本原多項式 `0b1101`）直接寫成 C++ 程式碼：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

class GF8 {
private:
    int exp_table[8]; // 步數 -> 多項式數值
    int log_table[8]; // 多項式數值 -> 步數

public:
    // 建構子：初始化並建立 8 格查表陣列
    GF8() {
        int poly = 0b1101; // 本原多項式 x^3 + x^2 + 1
        int val = 1;       // 從 001 (1) 出發

        for (int i = 0; i < 7; i++) {
            exp_table[i] = val; // 紀錄步數對應的數值
            log_table[val] = i; // 紀錄數值反查的步數

            val = val << 1;     // 左移 1 位 = 乘上生成元 x (010)
            if (val >= 8) {     // 第 4 bit 為 1 (出現 x^3) 代表溢位
                val ^= poly;    // XOR 1101 降次，壓回 3 Bits 內
            }
        }
        exp_table[7] = 1;       // 走滿 7 步繞回 001，確保 inv(1) 正確
    }

    int add(int a, int b) { return a ^ b; }
    int sub(int a, int b) { return a ^ b; }

    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] + log_table[b]) % 7];
    }

    int div(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] - log_table[b] + 7) % 7];
    }

    int inv(int a) {
        if (a == 0) return 0;
        return exp_table[7 - log_table[a]];
    }
};
```

## 程式實作（二）：$GF(2^8)$ C++ 實作

把完全相同的結構放大到 **1 Byte（8 Bits）**：陣列大小改為 `256`、週期改為 `255`、模數換成 `0x11D`：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>

class GF256 {
private:

public:

        exp_table[255] = 1;     // 走滿 255 步繞回 1，確保 inv(1) 正確

        return exp_table[(log_table[a] - log_table[b] + 255) % 255];
    }

    int inv(int a) {
        if (a == 0) return 0;

    }
};
```

## 程式實作（三）：推廣到任意 $GF(2^n)$ 通用 C++ 實作

只要令 `size = 1 << n`（即 $2^n$），把前兩頁寫死的 `8`、`256` 換成 `size`，同一套程式碼就能通用於任意 $GF(2^n)$：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

template <int n>
class GFn {
private:
    static const int size = 1 << n; // 元素總數 size = 2^n
    int exp_table[size];            // 步數 -> 多項式數值
    int log_table[size];            // 多項式數值 -> 步數

public:
    // 建構子：初始化並建立 size (2^n) 格查表陣列
    GFn(int poly) {
        int val = 1; // 從 1 出發

        for (int i = 0; i < size - 1; i++) {
            exp_table[i] = val; // 紀錄步數對應的數值
            log_table[val] = i; // 紀錄數值反查的步數

            val = val << 1;     // 左移 1 位 = 乘上生成元 x
            if (val >= size) {  // 第 n+1 bit 為 1 (出現 x^n) 代表溢位
                val ^= poly;    // XOR 本原多項式降次，壓回 n Bits 內
            }
        }
        exp_table[size - 1] = 1; // 走滿 size - 1 步繞回 1，確保 inv(1) 正確
    }

    int add(int a, int b) { return a ^ b; }
    int sub(int a, int b) { return a ^ b; }

    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] + log_table[b]) % (size - 1)];
    }

    int div(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] - log_table[b] + (size - 1)) % (size - 1)];
    }

    int inv(int a) {
        if (a == 0) return 0;
        return exp_table[(size - 1) - log_table[a]];
    }
};
```
