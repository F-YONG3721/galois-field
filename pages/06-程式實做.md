## 程式實作：$GF(2^8)$ 查表法原理

<div class="grid grid-cols-2 gap-4 mt-3 text-sm">

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**① 為什麼要用查表法？（空間換時間）**  
直接做多項式展開與長除法需要跑迴圈，處理海量 Byte 太慢；預先建表即可將運算降為 **$O(1)$** 陣列讀取。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**② 關鍵數學：本原多項式 `0x11D` 與生成元 $g = 2$ ($x$)**  
選用 `0b100011101`（$x^8+x^4+x^3+x^2+1$，QR Code 標準），生成元直接用 **$g = 2$**（左移 1 位 `<< 1`），連乘 $g^0 \sim g^{254}$ 剛好不重複走遍全部 255 個非零元素。

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**③ 兩張表互相對照（次方數 $\leftrightarrow$ 係數）**  
- **`exp_table[次方數]`**：給**次方數** $\to$ 查出對應的**係數（數值）**  
- **`log_table[係數]`**：給**係數（數值）** $\to$ 反查出對應的**次方數**

</div>

<div v-click class="bg-white/5 border border-white/10 rounded-xl p-3.5">

**④ 乘法變「次方數相加」、反元素變「次方數相減」**  
- **乘法**：查出兩數的**次方數** $\to$ **相加**（$\bmod 255$）$\to$ 查回係數  
- **反元素**：用 `255` **減掉**它的**次方數** $\to$ 查回係數（因 $g^{255}=1$）

</div>

</div>

### 1. 建表實作：`uint8_t` 與雙倍長度表技巧

<div class="grid grid-cols-12 gap-5 items-start mt-2">
<div class="col-span-7">

```cpp {1-2|4-7|9-10}
constexpr int POLY = 0x11D;         // x^8 + x^4 + x^3 + x^2 + 1
uint8_t exp[512], log[256];         // 1 Byte 陣列，exp 開雙倍省去 % 255

int v = 1;
for (int i = 0; i < 255; ++i) {
    exp[i] = exp[i + 255] = v;      // 一次寫入兩份週期（自動補齊 exp[255]）
    log[v] = i;                     // 同步建立反查表（係數 -> 次方數）

    // 乘生成元 g = 2：若第 8 bit (0x80) 為 1，左移後溢位就 XOR 0x11D
    v = (v << 1) ^ ((v & 0x80) ? POLY : 0);
}
```

</div>
<div class="col-span-5 text-xs space-y-2">

<div class="bg-white/5 border border-sky-400/40 rounded-lg p-2.5">
  <div class="font-bold text-sky-400">Step 1：1 Byte 型別 ＋ 雙倍表設計</div>
  用 <code>uint8_t</code> 精準對應 1 Byte；<code>exp[512]</code> 存兩份週期，之後乘法連 <code>% 255</code> 都省掉！
</div>

<div v-click="1" class="bg-white/5 border border-emerald-400/40 rounded-lg p-2.5 [&_th]:!py-0.5 [&_td]:!py-0.5 [&_th]:!px-1.5 [&_td]:!px-1.5">
  <div class="font-bold text-emerald-400 mb-1">Step 2：單一迴圈同步寫入雙表</div>

| 次方數 `i` | `exp[i]` (係數) | `log[係數]` (次方數) |
|:---:|:---:|:---:|
| `0` | **1**（同步寫 `exp[255]=1`） | `log[1] = 0` |
| `1` | **2** | `log[2] = 1` |
| `2` | **4** | `log[4] = 2` |
| `3` | **8** | `log[8] = 3` |

</div>

<div v-click="2" class="bg-amber-500/15 border border-amber-400/40 rounded-lg p-2.5 text-amber-200">
  <div class="font-bold text-amber-300">Step 3：一行完成乘 2 ＆ 溢位降次（i = 8）</div>
  <code>v = 128 (0x80)</code> 最高位為 1 → 左移變 <code>256</code><br/>
  <code>256 ^ 0x11D = <b>29</b></code>（自動壓回 1 Byte！）
</div>

### 2. $O(1)$ 四則與反元素實作（無 `% 255` 極速版）

<div class="grid grid-cols-12 gap-5 items-start mt-2">
<div class="col-span-7">

```cpp {1-3|5-8|10-13}
uint8_t add(uint8_t a, uint8_t b) {
    return a ^ b;                   // 加減法皆為 XOR
}

uint8_t mul(uint8_t a, uint8_t b) {
    if (!a || !b) return 0;
    return exp[log[a] + log[b]];    // 雙倍表直接查，免取餘數！
}

uint8_t inv(uint8_t a) {
    if (!a) return 0;
    return exp[255 - log[a]];       // exp[255] 已自動填為 1
}
```

</div>
<div class="col-span-5 text-xs space-y-2.5">

<div class="bg-white/5 border border-sky-400/40 rounded-lg p-3">
  <div class="font-bold text-sky-400 mb-1">Step 1：加法 add(2, 4)</div>
  <div><code>2 = 0000 0010</code>、<code>4 = 0000 0100</code></div>
  <div class="text-emerald-400 font-bold mt-0.5">XOR 結果 = <code>0000 0110</code> = <b>6</b> ✓</div>
</div>

<div v-click="1" class="bg-white/5 border border-emerald-400/40 rounded-lg p-3">
  <div class="font-bold text-emerald-400 mb-1">Step 2：乘法 mul(2, 4)</div>
  <div>① 查次方數：<code>log[2] = 1</code>、<code>log[4] = 2</code></div>
  <div>② 直接相加：<code>1 + 2 = 3</code>（最大 508 &lt; 512）</div>
  <div class="text-emerald-400 font-bold mt-0.5">③ 查回係數：<code>exp[3] = <b>8</b></code> ✓</div>
</div>

<div v-click="2" class="bg-white/5 border border-pink-400/40 rounded-lg p-3">
  <div class="font-bold text-pink-400 mb-1">Step 3：反元素 inv(2)</div>
  <div>① 查次方數：<code>log[2] = 1</code></div>
  <div>② 次方相減：<code>255 - 1 = 254</code></div>
  <div class="text-emerald-400 font-bold mt-0.5">③ 查回係數：<code>exp[254] = <b>142</b></code>（<code>2 × 142 = 1</code>）✓</div>

### 3. 完整可執行 C++ 程式碼（`struct GF256`）

```cpp {lines:true, maxHeight:'400px'}
#include <cstdint>
#include <iostream>

struct GF256 {
    static constexpr int POLY = 0x11D; // x^8 + x^4 + x^3 + x^2 + 1
    uint8_t exp[512]{}, log[256]{};

    GF256() {
        int v = 1;
        for (int i = 0; i < 255; ++i) {
            exp[i] = exp[i + 255] = v; // 雙倍表省去乘法時的 % 255
            log[v] = i;
            v = (v << 1) ^ ((v & 0x80) ? POLY : 0);
        }
    }

    uint8_t add(uint8_t a, uint8_t b) const { return a ^ b; }
    uint8_t mul(uint8_t a, uint8_t b) const { return (!a || !b) ? 0 : exp[log[a] + log[b]]; }
    uint8_t inv(uint8_t a) const { return !a ? 0 : exp[255 - log[a]]; }
};

int main() {
    GF256 gf;
    std::cout << "2 + 4 = "      << (int)gf.add(2, 4)   << '\n'; // 6
    std::cout << "2 * 4 = "      << (int)gf.mul(2, 4)   << '\n'; // 8
    std::cout << "inv(2) = "     << (int)gf.inv(2)      << '\n'; // 142
    std::cout << "2 * inv(2) = " << (int)gf.mul(2, 142) << '\n'; // 1
}
```

### 進入真實世界：為什麼是 $GF(2^8)$ ？

前面我們利用 $GF(2^3)$ 徹底理解了多項式的 XOR 抵銷與降次代換。但回到真實的計算機科學領域，我們最需要也最常使用的，是 **$GF(2^8)$**。

#### 1. 什麼時候會發生溢位 (Overflow)？
在 $GF(2^8)$ 的空間中，一個元素剛好對應電腦底層的 **1 Byte (8 Bits)**。
這 8 個 Bits 能表示的最高次方是 **$x^7$**（例如二進位 `11111111` $= x^7+x^6+...+1$）。

* **觸發溢位的瞬間**：當我們進行乘法運算時，只要產生了 **$x^8$ 或更高的次方**，就代表需要「第 9 個 Bit」才能儲存，這在 8-bit 的資料結構中就會發生 Overflow。
* **解決方案**：一旦偵測到 $x^8$ 出現，系統就會立刻除以 8 次的不可約多項式 $m(x)$ ，透過 XOR 取餘數，將超出邊界的次方完美壓回 1 Byte 的空間內，保證資料永遠不會因溢位而遺失或失真。

---
---
#### 2. 從 $GF(2^3)$ 到 $GF(2^8)$ 的根本差異
推廣到 8 次方後，數學運算規則（加減法等於 XOR、找質式降次）完全沒有改變，真正的差異在於**工程上的意義**：
* **$GF(2^3)$**：空間太小（只有 8 種變化），只能作為數學課堂上的概念模型。
* **$GF(2^8)$**：空間剛好是 256 種變化，完美對應 ASCII 碼、像素顏色 (0~255)、以及記憶體中的任何一個 Byte。**我們把電腦裡所有的 Byte，都變成了可以做嚴格代數運算的數學實體。**
