## 上週重點回顧

<div class="grid grid-cols-3 gap-4 mt-5 text-sm">

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-4">

### 1. 什麼是體 (Field)？
- 一個有限集合，同時定義**加法**與**乘法**
- 運算結果永遠留在集合內（**封閉性**）
- 每個非零元素皆存在唯一**乘法反元素**（可做除法、可 100% 還原）

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4">

### 2. 常數與多項式
- **常數 $GF(p)$**：整數 $\bmod$ 質數 $p$（如 $GF(7)$）
- **多項式 $GF(2^n)$**：$n$ 個 Bits 直接對應 $n-1$ 次多項式，係數只能是 `0` 或 `1`
- 係數 $\bmod 2$：加減法完全等同 **XOR ($\oplus$)**

</div>

<div class="bg-white/5 border border-amber-400/40 rounded-xl p-4">

### 3. 如果 Overflow 怎麼辦？
- 乘法產生最高次方 $\ge n$（超出 $n$ Bits 邊界）時發生 **Overflow**
- 解法：除以預先選定的 $n$ 次**不可約多項式 $m(x)$** 取餘數
- 餘式次方必定 $< n$，完美壓回固定位寬內

</div>

</div>

## 為什麼要改用查表法？

<div class="space-y-4 mt-4 text-sm">

<div class="bg-white/5 border border-red-400/40 rounded-xl p-4 space-y-1.5">

### 1. 一般做法：每次相乘都直接硬算（太慢）
- **怎麼算**：每次遇到兩個多項式相乘，都要當場跑雙層迴圈做「逐項展開 ＋ 長除法取餘數」，單次時間複雜度為 **$O(n^2)$**（就算改用二進位左移也要跑 $O(n)$ 迴圈）。
- **問題在哪**：加密一個檔案動輒要算**上億次**乘法，每次都重新跑迴圈會浪費大量 CPU 時間。

</div>

<div class="bg-white/5 border border-emerald-400/40 rounded-xl p-4 space-y-1.5">

### 2. 解決方法：預先建表 ＋ $O(1)$ 查表法（空間換時間）
- **階段一（啟動時先把表建好，只算 1 次）**：程式剛啟動時，先用二進位 **Shift + XOR** 把所有非零數字與次方數的對應關係算過一輪，存進 `exp_table` 與 `log_table` 兩張字典。
- **階段二（實際算乘除時，翻字典把次方相加／相減）**：之後遇到 `A × B` 時**完全不用展開多項式**！只要查字典找出 `A`、`B` 各是第幾次方，把兩個次方數**直接做整數相加**（因為 $g^a \times g^b = g^{a+b}$），再查回對應的數字就是答案！
- **為什麼比較快**：建表只花極小的一次性成本（$GF(2^8)$ 僅 255 步），之後上億次運算通通**免跑迴圈**，單次時間複雜度降為 **$O(1)$**！

</div>

</div>

## $GF(2^8)$ 二進位乘法：Shift + XOR 計算方式

把「乘上 $x$」寫成二進位左移 1 位：若左移前最高位 $b_7 = 1$，左移後**第 9 個 bit（$x^8$）就會變成 `1` 溢位**，此時 XOR 不可約多項式即可同時消掉第 9 bit 並完成降次：

$$x \times f(x) = \begin{cases} (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) & \text{if } b_7 = 0 \text{（第 9 bit 為 0，未溢位）} \\ (b_6 b_5 b_4 b_3 b_2 b_1 b_0 0) \oplus (00011011) & \text{if } b_7 = 1 \text{（第 9 bit 為 1，XOR 模數降次）} \end{cases}$$

  <div class="font-sans font-bold text-sky-400 mb-1">經典範例：f = 01010111 × g = 10000011，模 0x11B</div>
  <div><span class="text-emerald-400">x⁰·f</span> = 01010111 <span class="text-emerald-400">← 選取 (g 第 0 位=1)</span></div>
  <div><span class="text-emerald-400">x¹·f</span> = <span class="opacity-60">0</span>|10101110 <span class="text-emerald-400">← 選取 (g 第 1 位=1)</span></div>
  <div>x²·f = <span class="text-red-300 font-bold">1</span>|01011100 ⊕ <span class="text-amber-300">1|00011011</span> = 01000111</div>

## 查表法原理（一）：`exp_table`（Exponential 指數表）

在建立表格前，我們先用一條核心式子把三個符號**明確定義**清楚：

$$g^i \equiv v \pmod{m(x)}$$

<div class="grid grid-cols-3 gap-3 mt-2 text-xs">

<div class="bg-white/5 border border-white/15 rounded-lg p-2.5">

**$g$：生成元 (Generator)**  
固定選好的連乘底數。選用本原多項式時，$g = x$（二進位 `10` = 整數 **2**）。  
（註：$g$ 不一定等於質數 $p$，如 AES 模 `0x11B` 時 $g=3$）

</div>

<div class="bg-white/5 border border-white/15 rounded-lg p-2.5">

**$i$：指數 (Exponent)**  
代表 $g$ 自乘了幾次，範圍為整數 `0` 到 $M-1$（其中非零元素總數 $M = 2^n - 1$）。

</div>

<div class="bg-white/5 border border-white/15 rounded-lg p-2.5">

**$v$：有限體元素值 (Value)**  
$g^i$ 取餘數後得到的多項式元素（程式中以二進位對應的整數 `1`～$M$ 儲存）。

</div>

</div>

<div class="bg-white/5 border border-sky-400/40 rounded-xl p-3.5 mt-3 text-xs space-y-1">

**`exp_table[i] = v`（Exponential Table：輸入指數 $i \longrightarrow$ 查出元素值 $v$）**
- **建表方式**：從 `exp_table[0] = 1`（$g^0=1$）出發，每往後一格就做一次 **Shift + XOR** 算出 $g^i$。
- **必定繞回起點 `1`**：因為 $GF(2^n)$ 非零元素固定只有 $M = 2^n - 1$ 個，依**拉格朗日定理**必滿足 $g^M = 1$！走完 `0`～$M-1$ 不重複填滿所有非零元素後，第 $M$ 步 **100% 保證繞回 `1`**（結尾也補上 `exp_table[M] = 1` 備用）。

</div>

## 查表法原理（二）：`log_table`（Logarithm 對數表）與兩表差異

`log` 全名為 **Logarithm（對數）**，是 `exp` 的反函數：若 $g^i \equiv v$，則 $\log_g(v) = i$。

<div class="mt-3 bg-white/5 border border-white/10 rounded-xl px-4 py-2.5 text-sm [&_th]:!py-2 [&_td]:!py-2">

| 比較項目 | `exp_table`（指數表） | `log_table`（對數表） |
|:---:|:---|:---|
| **英文全名** | **Exponential** Table | **Logarithm** Table |
| **陣列索引（輸入）** | 放 **指數 $i$**（`0` ～ $M$） | 放 **元素值 $v$**（`1` ～ $M$） |
| **陣列內容（輸出）** | 存 **元素值 $v$**（$= g^i$） | 存 **指數 $i$**（$= \log_g v$） |
| **程式碼寫法** | `exp_table[i] = val;` | `log_table[val] = i;`（直接把索引與內容對調！） |
| **使用時機** | 運算**最後一步**：把算完的指數變回元素值 | 運算**第一步**：把輸入元素 `a, b` 換成指數才能相加減 |
| **特殊邊界** | `exp_table[M] = 1`（繞回起點） | **`0` 沒有對數**（`log_table[0]` 不可查，須先防呆） |

</div>

<div class="mt-3 bg-emerald-500/10 border border-emerald-400/40 rounded-xl p-3 text-xs text-center">

一句話分清楚：**`exp_table` 負責「指數 $\to$ 元素值」**；**`log_table` 負責「元素值 $\to$ 指數」**，兩張表存的是同一組配對，只是查詢方向相反！

</div>

## 兩表合體：$O(1)$ 查表四則與反元素規則

有了 `log_table`（換成指數）與 `exp_table`（換回元素值），令非零週期 **$M = 2^n - 1$**，所有運算都能在 **$O(1)$** 完成：

<div class="mt-4 bg-white/5 border border-white/10 rounded-xl px-5 py-3 text-sm [&_th]:!py-2.5 [&_td]:!py-2.5">

| 運算項目 | 數學依據 | 查表三步驟流程 | 對應 C++ 程式碼 |
|:---:|:---:|:---|:---|
| **加／減法** | 係數 $\bmod 2$ | 直接位元互斥或（免查表） | `a ^ b` |
| **乘法 `mul`** | $g^i \cdot g^j = g^{(i+j)\bmod M}$ | 查 `log` 得指數 $\to$ **指數相加** $\to$ 查 `exp` | `exp_table[(log_table[a] + log_table[b]) % M]` |
| **除法 `div`** | $g^i \div g^j = g^{(i-j+M)\bmod M}$ | 查 `log` 得指數 $\to$ **指數相減** $\to$ 查 `exp` | `exp_table[(log_table[a] - log_table[b] + M) % M]` |
| **反元素 `inv`** | $g^{-i} = g^{M-i}$（因 $g^M=1$） | 查 `log` 得指數 $\to$ **$M$ 減指數** $\to$ 查 `exp` | `exp_table[M - log_table[a]]` |

</div>

<div class="mt-3 text-xs opacity-85 space-y-1">

- **為什麼除法要 `+ M`？** 避免 `log_table[a] - log_table[b]` 出現負數，先加一個週期 $M$ 再 `% M` 結果同餘且保證為正。
- **為什麼要先判斷 `0`？** 因為元素 `0` 不存在對數，`mul / div / inv` 只要遇到 `0` 就直接回傳 `0`。

</div>

## $GF(2^3)$ 完整演練（二）：用建好的表執行運算函式

上方建完表後，記憶體裡就有了這兩排固定陣列（週期 $M = 7$）：

<div class="grid grid-cols-2 gap-3 mt-2 text-xs [&_th]:!py-1 [&_td]:!py-1">
<div class="bg-white/5 border border-sky-400/40 rounded-lg p-2">

**正向表 `exp_table[0..7]`（輸入指數 → 得元素值）**

| 索引 `i` | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **`exp[i]`** | **1** | **2** | **4** | **5** | **7** | **3** | **6** | **1** |

</div>
<div class="bg-white/5 border border-emerald-400/40 rounded-lg p-2">

**反向表 `log_table[0..7]`（輸入元素值 → 得指數）**

| 索引 `v` | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **`log[v]`** | — | **0** | **1** | **5** | **2** | **3** | **6** | **4** |

<div class="mt-2.5 bg-white/5 border border-amber-400/40 rounded-xl p-3 text-xs space-y-1">

**直接把數字代進 C++ 函式查表（全程 0 迴圈！）：**
- **`add(5, 3)` / `sub(5, 3)`** $\longrightarrow$ `5 ^ 3 = 101 ^ 011 = 110 =` **`6`**
- **`mul(7, 7)`** $\longrightarrow$ `exp[(log[7] + log[7]) % 7] = exp[(4 + 4) % 7] = exp[1] =` **`2`**（與第 05 章手算一致！）
- **`div(2, 7)`** $\longrightarrow$ `exp[(log[2] - log[7] + 7) % 7] = exp[(1 - 4 + 7) % 7] = exp[4] =` **`7`**（驗證 `7 × 7 = 2`！）
- **`inv(7)`** $\longrightarrow$ `exp[7 - log[7]] = exp[7 - 4] = exp[3] =` **`5`**（驗證 `7 × 5 = 1`！）
- **`inv(1)`** $\longrightarrow$ `exp[7 - log[1]] = exp[7 - 0] = exp[7] =` **`1`**（驗證補 `exp[7] = 1` 的作用！）

## 程式實作（一）：$GF(2^3)$ C++ 實作（$M = 7$）

把上一頁手算演練的 **$GF(2^3)$**（本原多項式 `0b1101`、週期 $M = 7$）直接寫成 C++ 程式碼：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

class GF8 {
private:
    int exp_table[8]; // 次方數 -> 係數 (1~7)
    int log_table[8]; // 係數 (1~7) -> 次方數

public:
    // 建構子：初始化並建立 8 格查表陣列
    GF8() {
        int poly = 0b1101; // 本原多項式 x^3 + x^2 + 1
        int val = 1;       // 從 g^0 = 1 開始

        for (int i = 0; i < 7; i++) {
            exp_table[i] = val; // 紀錄次方數對應的係數
            log_table[val] = i; // 紀錄係數反查的次方數

            val = val << 1;     // 左移 1 位 = 乘上生成元 g = 2 (x)
            if (val >= 8) {     // 第 4 bit 為 1 (出現 x^3) 代表溢位
                val ^= poly;    // XOR 0b1101 降次，壓回 3 Bits 內
            }
        }
        exp_table[7] = 1;       // 補上 g^7 = 1，確保 inv(1) 正確
    }

    int add(int a, int b) { return a ^ b; }
    int sub(int a, int b) { return a ^ b; }

    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] + log_table[b]) % 7];
    }

    int div(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return exp_table[(log_table[a] - log_table[b] + 7) % 7];
    }

    int inv(int a) {
        if (a == 0) return 0;
        return exp_table[7 - log_table[a]];
    }
};
```

## 程式實作（二）：$GF(2^8)$ C++ 實作（$M = 255$）

把架構完全不變地放大到 **1 Byte（8 Bits）**：陣列改為 `256`、溢位門檻改為 `256`、模數換成 `0x11D`、週期改為 `255`，就是真實工程使用的 $GF(2^8)$：

```cpp {lines:true, maxHeight:'390px'}
#include <iostream>
using namespace std;

class GF256 {
private:
    int exp_table[256]; // 次方數 -> 係數 (數值)
    int log_table[256]; // 係數 (數值) -> 次方數

public:
    // 建構子：初始化並建立查表陣列
    GF256() {
        int poly = 0x11D; // 本原多項式 x^8 + x^4 + x^3 + x^2 + 1
        int val = 1;      // 從 g^0 = 1 開始

        // 依序產生 1~255 全部 255 個非零元素
        for (int i = 0; i < 255; i++) {
            exp_table[i] = val; // 紀錄次方數對應的係數
            log_table[val] = i; // 紀錄係數反查的次方數

            val = val << 1;     // 左移 1 位 = 乘上生成元 g = 2 (x)
            if (val >= 256) {   // 第 9 bit 為 1 (出現 x^8) 代表溢位
                val ^= poly;    // XOR 0x11D 降次，壓回 1 Byte 內
            }
        }
        exp_table[255] = 1;     // 補上 g^255 = 1，確保 inv(1) 正確
    }

    // 加法：無進位 XOR
    int add(int a, int b) {
        return a ^ b;
    }

    // 減法：係數 mod 2 下與加法相同
    int sub(int a, int b) {
        return a ^ b;
    }

    // 乘法：次方數相加 (mod 255) 再查回係數
    int mul(int a, int b) {
        if (a == 0 || b == 0) return 0; // 0 沒有對應的次方數
        return exp_table[(log_table[a] + log_table[b]) % 255];
    }

    // 除法：次方數相減 (加 255 避免負數) 再查回係數
    int div(int a, int b) {
        if (a == 0 || b == 0) return 0; // 避免 0 或除以 0
        return exp_table[(log_table[a] - log_table[b] + 255) % 255];
    }

    // 乘法反元素：用 255 減掉次方數再查回係數
    int inv(int a) {
        if (a == 0) return 0; // 0 沒有乘法反元素
        return exp_table[255 - log_table[a]];
    }
};
```
